# 充电·岛（DevicePill）

ColorOS 16 充电流体云 · 金标充电显示

**无需 root**，专为 OPPO Find X9 Ultra 等 ColorOS 16 设备优化。

---

## 功能

- ⚡ **充电实时监控**：功率（W）、电压、电流、温度、健康度、电池技术
- 🔋 **Active Ring**：4 色渐变圆环（动感/极紫/海洋/日落 四主题可切换）
- 📈 **功率曲线**：60 秒历史折线图
- 🌡️ **温度曲线**：60 秒温度趋势
- 🏝️ **流体云胶囊**：充电时摄像头旁显示实时数据
- 🏝️ **锁屏岛**：展开显示完整参数
- 🔔 **常亮显示**：锁屏常驻
- 🚀 **开机自启**

---

## 安装

从 [Releases](../../releases) 下载最新 APK → 安装 → 按下方设置指南操作。

---

## ⚠️ 设置指南（必须！）

### 1. 授权通知权限
首次打开 App 弹窗点「允许」，错过可在 App 内红色卡片点击授权。

### 2. 开启流体云 ⭐ **最关键**
```
设置 → 通知与状态栏 → 流体云 → DevicePill → 打开
```

### 3. 允许锁屏显示
```
设置 → 通知与状态栏 → App 通知管理 → DevicePill → 锁屏通知 → 显示
```

### 4. 启动并验证
回到 App → 点击「启动流体云」→ 插充电器 → 摄像头旁出现金标胶囊

## 主题

顶部芯片可切换 4 种配色（从 LLMonitor APK 反编译提取）：

| 主题 | 环形渐变 |
|------|---------|
| 动感 | 青 → 橙 → 黄 → 绿 |
| 极紫 | 浅紫 → 紫 → 紫罗兰 → 靛蓝 |
| 海洋 | 浅蓝 → 中蓝 → 深蓝 → 天蓝 |
| 日落 | 金橙 → 橙 → 深橙 → 红橙 |

## 常见问题

**Q: 没看到流体云胶囊？**
A: 系统设置 → 通知与状态栏 → 流体云 → 打开 DevicePill

**Q: 锁屏不显示？**
A: 设置 → 通知 → DevicePill → 锁屏通知 → 显示所有

**Q: 功率 0W？**
A: 部分设备/充电器不返回电流值，电压和温度仍正常

**Q: 后台被杀？**
A: 设置 → 应用 → DevicePill → 电池 → 不限制
